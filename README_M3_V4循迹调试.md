# M3：V4 路线感知循迹与 VOFA 调试

V4 有效目标负责纯追踪转向；当前追踪曲率与最新有效末端曲率负责弯道速度规划。
单边寻线、第二采样点回退、曲率未知、转向限幅、短时丢目标有独立限速。
这是一组待实车验证的初始控制参数，不保证消除实际转角标定、视觉坐标或机械极限导致的偏外。

## 行驶逻辑

1. 本地选 M3 并 RUN 后等待新的有效目标，等待上限仍为1 s。末端信息不能单独启动车辆。
2. 以目标实际XY计算左正右负的追踪曲率 `k_pp=-2*X/(X*X+Y*Y)`，X/Y单位m。
3. 输出转角 `atan(0.145*当前增益*k_pp)`，维持原正常行驶限幅±0.35 rad（约±20.05°）。
4. V4减速依据 `K=max(abs(当前增益*k_pp), latest_endpoint_abs_curvature_cm_inv*100)`。
   只有新鲜（小于150ms）、有效且在后轴前方的末端曲率参与；极端值在换单位前限制，避免溢出。
   末端是可见路径终点，不是后轴处曲率，用于提前减速及选择直道/弯道增益，不直接叠加转向前馈。
5. 正常弯道期望速度 `clamp(TV-TCK*max(K-TCTH,0), min(TVMIN,TV), TV)`。
6. 多个降级条件可同时存在，取所有适用速度上限中的最小值。降级上限可以低于TVMIN；所有上限都不能抬高TV。
7. V4从0平滑起步；首次起步提速受TSTART限制，后续提速受TACC限制，减速受TDEC限制。下降上限是期望值，执行速度按TDEC逐步下降，不是瞬间到达。
8. 无效目标立即进入保持；停止发有效数据满150ms也进入保持。保持最后有效XY及转向，限制速度且禁止加速。
9. 只有新合法有效目标刷新1000ms计时；端点-only、无效、CRC错误都不刷新。满1000ms立即停车、舵机回中，停车不经过速度斜坡。
10. 截止前恢复有效目标立即使用新XY，速度平滑恢复。超时停车后必须重新RUN且收到新的有效目标，不自动重启。

UART错误、遥控STOP、本地停止、电源/使能异常仍立即停止。
不根据末端绝对曲率猜左右，不把预瞄无效但末端有效的数据直接当目标。
有效目标太近或不满足几何条件时停止，避免追踪奇点。

## 条件、速度及控制状态

| 情况 | 控制状态I42 | 默认期望速度处理 |
|---|---:|---|
| 停止/等待 | 0 | 输出0 |
| 正常双边且末端曲率可用 | 1 | 基础0.45m/s，按曲率降至正常最低0.30m/s |
| 单边（mode=2/3） | 2 | 上限0.25m/s |
| 目标来自第二采样点 | 3 | 上限0.20m/s |
| 前方末端曲率不可用/过期 | 4 | 上限0.25m/s，仍参考纯追踪曲率减速 |
| 目标无效或有效目标年龄>=150ms | 5 | 上限0.20m/s，且不高于进入保持前速度 |
| 计算转角达到正常行驶限幅 | 6 | 上限0.20m/s |

主状态优先级为：保持 > 限幅 > 第二点回退 > 曲率未知 > 单边 > 正常。
I43同时保留原因位：1单边、2第二点回退、4曲率未知、8保持、16限幅；组合时相加。
例I43=3表示单边+回退，I43=12表示曲率未知+保持。
mode仅表示实际寻线方式，不表示完整置信度；V4尚未提供拟合残差、横向偏差或路线航向。

## VOFA 连接与命令

USART3 PC10/PC11，115200、8N1、JustFloat、20Hz，67个float通道I0～I66。
每帧272字节（67x4+4字节帧尾0000807F）。上电自动发送。
所有命令为ASCII，分号结尾。滑条用占位符替换固定数值。

| 功能 | 固定命令/默认值 | 滑条发送内容 | 允许范围 |
|---|---|---|---|
| 基础速度m/s | `TV=0.45;` | `TV=%.2f;` | 0.01～0.8 |
| 正常弯道最低速度m/s | `TVMIN=0.30;` | `TVMIN=%.2f;` | 0.01～0.8 |
| 直道转向增益 | `TPGS=0.95;` | `TPGS=%.2f;` | 0.5～1.5 |
| 弯道转向增益 | `TPGC=1.40;` | `TPGC=%.2f;` | 0.5～1.5 |
| 进入弯道曲率m^-1 | `TGEN=0.82;` | `TGEN=%.2f;` | 大于TGEX，最大20 |
| 回到直道曲率m^-1 | `TGEX=0.31;` | `TGEX=%.2f;` | 0～小于TGEN |
| 减速起始曲率m^-1 | `TCTH=0.82;` | `TCTH=%.2f;` | 0～20 |
| 曲率减速力度(m/s)/(m^-1) | `TCK=0.08;` | `TCK=%.3f;` | 0～1 |
| 单边限速m/s | `TSINGLE=0.25;` | `TSINGLE=%.2f;` | 0.01～0.8 |

| 曲率未知限速m/s | `TUNKNOWN=0.25;` | `TUNKNOWN=%.2f;` | 0.01～0.8 |
| 丢目标保持限速m/s | `THOLD=0.20;` | `THOLD=%.2f;` | 0.01～0.8 |
| 转向限幅时限速m/s | `TSAT=0.20;` | `TSAT=%.2f;` | 0.01～0.8 |
| 赛道加速度m/s² | `TACC=0.215;` | `TACC=%.3f;` | 0.05～3 |
| 起步加速度m/s² | `TSTART=0.400;` | `TSTART=%.3f;` | 0.05～3 |
| 减速度m/s² | `TDEC=0.80;` | `TDEC=%.2f;` | 0.05～5 |

`M=3;RUN=1;`启动；`RUN=0;`停止。`TRESET=1;`恢复代码默认参数并重置控制状态；运行中执行会重新平滑起步。
参数为RAM设置，重启恢复代码默认值。
增益放大整个追踪曲率，不仅放大纠偏；直道默认0.95，弯道默认1.40，可每次调整0.05小范围实测。达到限幅后增益不再增大实际输出转角。
V4不使用旧TXTH/TXK；它们保留给V3，因此旧滑条能收到命令但不会改变V4的减速。TKP/TKD/TKS/TDF仍拒绝，避免误以为旧PD参与M3。
V3继续使用旧X减速及速度响应，使用TPGC固定增益；上述V4降级限速和速度斜坡不作用于V3。
M1/M2/M4速度和手动舵机命令保持原行为。

## 推荐实车验证顺序

先TPG=1、较低TV测试正常双边、单边、第二点回退。用I42/I43确认状态、I45/I32确认速度过程。
验证丢目标后I59持续增加，I46/I47保持，I14/I22清零；有效新目标到来立即更新，1000ms无有效目标停车。
再观察I58/I20/I33，确认是否因限幅偏外；仅在未饱和且实际转角映射正确时小步调TPG。
末端曲率只提供弯曲程度，不能确定恢复方向；当前版本没有自动盲目加转向。
减速不能改变机械最小转弯半径。默认转角和速度参数需实车确认。

## 直道/弯道双增益

V4只根据新鲜且有效、位于后轴前方的末端道路曲率分类，单位从cm^-1乘100转为m^-1。
曲率>=TGEN进入弯道，<=TGEX回直道，两者之间保持原分类。分类与TCTH减速阈值独立；不使用X偏差或增益放大后的纯追踪曲率分类，避免直道纠偏触发增益反馈。
增益以每秒2.0的速度平滑变化，默认0.95到1.40约需0.23s。曲率不可用时冻结当前增益；目标不新鲜或无效时也冻结，包括盲走。启动尚无可靠曲率时使用弯道增益；V3使用固定弯道增益。
旧TPG命令同时设置直道和弯道增益，方便退回单增益；新的双增益调试请把原TPG滑条改为TPGC，再添加TPGS滑条，避免旧命令覆盖两套参数。
TGEX必须小于TGEN，违反关系的命令会被拒绝。TRESET=1恢复两套默认参数并重置分类。

| 新通道 | 含义 |
|---|---|
| I60 | 直道增益TPGS |
| I61 | 进入弯道阈值TGEN，m^-1 |
| I62 | 回到直道阈值TGEX，m^-1 |
| I63 | 当前实际转向增益（含平滑过渡） |
| I64 | 增益分类：0直道、1弯道、2曲率未知、3盲走保持、4旧V3 |

I0～I59索引保留，I48现在表示弯道增益。双增益新增I60～I64，起步加速度另增I65～I66；JustFloat帧为67个float加4字节帧尾。
末端曲率代表可见终点，不能完整描述整段道路；直弯交界时分类可能先于后轴进入弯道，需结合I41、I63、I64观察调节。达到机械或代码转角上限后，提高增益不会继续增加转角。

## 起步加速度与赛道加速度

当前默认基础速度0.45m/s、正常弯道最低速度0.30m/s；TSTART起步加速度和TACC赛道加速度独立保存，起步默认为0.40m/s²，赛道默认为0.215m/s²。TDEC减速度仍为0.80m/s²。
M3每次正式启动后，等待第一帧有效目标，从零速度开始使用TSTART；首次在新鲜有效目标下达到当时规划速度后，本次运行的后续提速使用TACC（含出弯、解除降级、盲走后恢复）。当时规划速度包含弯道减速、单边等限速，并不强求先达到基础速度。
短暂无效数据、速度下降、改变基础速度都不会重新触发起步阶段。起步过程中丢失目标继续执行原盲走减速，但不能因此判定起步完成。停止后重新启动、模式切换后启动或执行TRESET=1会重置起步阶段；TRESET在运行中会重新从零速度渐变。
本功能作用于V4的M3，M1/M2/M4及V3保持原速度逻辑。TSTART/TACC允许0.05～3.0m/s²，运行时VOFA参数重启恢复代码默认。

VOFA原“加速度”滑条继续发送`TACC=%.3f;`，可改名“赛道加速度”；新增“起步加速度”滑条发送`TSTART=%.3f;`。

| 新通道 | 内容 |
|---|---|
| I65 | 起步加速度TSTART，m/s² |
| I66 | 起步阶段标志：1起步中，0起步结束或未运行 |

I56仍为赛道加速度TACC，原I0～I64索引不变。达到首次规划速度的控制周期内I66变为0，下一周期提速使用TACC。

## 弯道进入确认

直道进入弯道需要连续 3 帧新的有效路线且曲率有效、曲率达到 TGEN；同一报文在多个控制周期中只计一次。低于 TGEN、路线失效、曲率未知或数据过期会清零进入计数；中间遗漏的报文不作为确认依据。启动默认直道状态；切换后仍使用原增益渐变。退出弯道仍使用 TGEX 滞回阈值，曲率减速不等待这 3 帧。
