## USER 按键与任务

上电停机，默认选择 **M1**。使能开关 PD3 为高、电池电压不低于 10 V，且 IMU 有新鲜有效数据时，允许启动。

| 操作 | 行为 |
|---|---|
| 单击 USER | 启动当前任务；运行中单击则停车 |
| 双击 USER | 先停车，再在 M1、M2 间切换，短鸣 50 ms；不会自动启动 |
| 长按 USER 约 0.5 秒 | 停车，松手后不会当成单击重新启动 |
| 上电时一直按住 USER | 不触发启动，需松开后重新操作 |

按键参考 `81V1/car-mspm0-three-mode/Hardware/key.c` 的单击、双击、长按识别，以及 `Control/control.c` 中 `Key()` 的“单击启停、双击停车切换”行为。移植后适配本板 PE0 低电平有效，增加 30 ms 消抖；第二次按下的识别窗口为第一次稳定松开后的 50～300 ms。单击会等待约 300 ms 排除双击，再执行启停。所有扫描在 TIM7 的 10 ms 控制周期内完成，不阻塞中断。

**M1：当前航向行驶 5 秒。** 单击被确认为启动事件时，读取当前 YAW 并保存为目标角；不发送 IMU 归零指令。以默认后轴中心速度 0.30 m/s 前进，位置式 PID 持续控制舵机修正航向。自首次下发运动指令计时 5000 ms 后停止电机、舵机回中、清除 PI/PID 状态，蜂鸣器鸣响 500 ms。计时按毫秒时钟计算，在 10 ms 控制周期上判断；并非等待轮速达到目标后再开始计时。

**M2：向前行驶，完成 90° 阿克曼转弯。** 在启动角基础上增加默认 `+90°`，以 0.20 m/s 前进，使用同一位置式 YAW PID 控制前轮转角，并按转弯几何关系计算两后轮目标速度。采用连续累计 YAW 增量判断转向进度，处理 `+180°/-180°` 跨界；距离目标角不超过约 1.2° 时停车并鸣响 500 ms。反方向转过 90°不会判为成功；超过 15 秒仍未完成则停车并显示 `TIME!`。该任务控制的是航向变化量，轨迹为受转角限幅和 PID 调节影响的前进曲线，不承诺固定圆弧半径或固定终点位置。

启动失败或运行中出现 IMU 超时、低电压、使能关闭时，停车并鸣响 200 ms。恢复条件后仍保持停机，需重新单击启动。任务完成后保留当前模式，也需要重新单击才能再次运行。

## 接线与定时器

| 功能 | 引脚/资源 | 配置 |
|---|---|---|
| 转向舵机信号 | **PC9 / TIM8_CH4 / AF3** | 50 Hz；PSC=167、ARR=19999；CCR4 单位为微秒 |
| 左后轮电机 A | PB8 / TIM10_CH1，PB9 / TIM11_CH1 | 保留原板双输入驱动方式 |
| 右后轮电机 B | PE5 / TIM9_CH1，PE6 / TIM9_CH2 | 独立 PWM 输出 |
| 左轮编码器 A | PA15 / TIM2_CH1，PB3 / TIM2_CH2 | 默认计数正号对应前进 |
| 右轮编码器 B | PB4 / TIM3_CH1，PB5 / TIM3_CH2 | 默认对原始计数取负后对应前进 |
| USER 按键 | PE0 | 内部上拉、低电平按下 |
| 蜂鸣器 | PA8 | 高电平响，沿用原工程定义 |
| 电机使能输入 | PD3 | 高电平允许运动 |
| 六轴 IMU | USART2：PA3 RX，PA2 TX | 115200，保留原 `5A BB ... SUM` 11 字节角度帧解析 |
| 控制循环 | TIM7 | 100 Hz / 10 ms；PSC=83、ARR=9999 |

时钟沿用原工程：8 MHz HSE、168 MHz 系统时钟。TIM8 使用 APB2 倍频后的 168 MHz 时钟，计数频率 1 MHz。舵机应按其额定电压供电并与控制板共地；PC9 是信号引脚。

C/D 两路不参与速度闭环，目标和输出固定为停机状态。模式切换不会再调用原履带遥控逻辑覆盖任务输出。

## 控制公式与参数

位置式角度 PID：

```text
e = wrap180(target_yaw - current_yaw)                 [deg]
integral += e * 0.01                                [deg*s]
steer = Kp*e + Ki*integral + Kd*filtered_de_dt        [rad]
```

输出为前轮等效转角，不是电机差速量。积分限幅 ±40 deg·s，饱和时采用条件积分，微分项使用低通滤波；启动时重置历史误差，避免目标阶跃造成微分冲击。YAW 误差及微分差值均处理角度跨界。

阿克曼后轮速度分配：`k = tan(steer)/wheelbase`，`v_left = v*(1-k*track/2)`，`v_right = v*(1+k*track/2)`。正转角对应左转，左轮为内侧轮。直行时两轮目标相同，不计算 `1/tan(0)`；超速时按相同比例缩放两轮目标，保持曲率比例。

左右轮分别保存增量式 PI 的输出与上次误差：`u[k] = u[k-1] + Kp*(e[k]-e[k-1]) + Ki*e[k]`。这里速度单位为 m/s，`Ki` 是每个 10 ms 周期使用的离散增益，不再乘 `dt`。每路累计输出限幅 ±16700；停机、任务切换或故障时同时清零，避免再次启动沿用旧 PWM。

以下参数均在 `BALANCE/ackermann_config.h`：

| 参数 | 默认值 | 含义 |
|---|---:|---|
| `ACK_WHEELBASE_M` / `ACK_TRACK_M` | 0.144 / 0.162 m | 轴距 / 后轮轮距，取自原工程阿克曼参数 |
| `ACK_WHEEL_DIAMETER_M` | 0.065 m | 驱动轮直径 |
| `ACK_GEAR_RATIO` / `ACK_ENCODER_LINES` | 30 / 13 | 减速比 / 编码器线数，4 倍频后每轮 1560 计数 |
| `ACK_SERVO_CENTER_US` | 1500 μs | 机械直行中位 |
| `ACK_SERVO_MIN_US` / `ACK_SERVO_MAX_US` | 1000 / 2000 μs | 舵机脉宽边界 |
| `ACK_MAX_STEER_RAD` | 0.35 rad，约 20.1° | 前轮等效转角限幅 |
| `ACK_SERVO_US_PER_RAD` / `ACK_SERVO_DIRECTION` | 1100 / -1 | 舵机连杆角度映射；默认左转时减小脉宽 |
| `ACK_SPEED_A_KP` / `ACK_SPEED_A_KI` | 1500 / 500 | 左轮独立 PI 参数 |
| `ACK_SPEED_B_KP` / `ACK_SPEED_B_KI` | 1500 / 500 | 右轮独立 PI 参数 |

机械参数、舵机中位与连杆比例不能仅凭源码确定。先架空检查两个电机的前进方向与编码器速度符号，再确认舵机正转角对应前轮左转、左转时 YAW 的增减方向，然后低速调轮速 PI 和航向 PID。电机方向使用 `ACK_MOTOR_A_SIGN/B_SIGN`，编码器方向使用 `ACK_ENCODER_A_SIGN/B_SIGN`，两者分别配置。修改参数后需要重新编译；`firmware` 内交付的文件不会随着编辑源码自动更新。

## OLED

使用 6×12 像素字体，每行最多 21 个字符，共五行，起始 Y 坐标为 0、12、24、36、48：

1. 模式、`READY/RUN/DONE/STOP/IMU!/PWR!/TIME!` 状态及任务时间。
2. `Y` 为当前 YAW，`R` 为目标 YAW，单位为度；末尾 `!` 表示 IMU 数据无效或超时。
3. 左轮目标/反馈速度，单位 mm/s。
4. 右轮目标/反馈速度，单位 mm/s。
5. 舵机脉宽及电池电压。

停止后时间冻结；目标 YAW 在未启动任务前为 0，启动后更新为本次目标角。

**2026-10-08 黑屏修复：** 上版显示层按 21 列排版，但沿用的 `OLED_ShowString()` 每个字符移动 8 像素，一行实际仅能放 16 个字符。最后一行溢出屏幕底部后调用 `OLED_Clear()`，再绘制补齐用的空格，导致一帧结束时显存全黑。已把字符步进改为实际字宽 6 像素，越界改为截断，并将六行 10 像素间距改为五行 12 像素间距。OLED 引脚和电气初始化保持原配置。

## 本次修复与验证

- 舵机输出由原错误的 `TIM12->CCR2` 改为 `TIM8->CCR4`，周期从 10 ms 改为 20 ms；初始化完成后才启动 PWM。
- 固定选择阿克曼几何参数，取消电位器及主程序中强制履带车型对本工程的影响。
- TIM7 控制中断在几何参数、模式和电机停止状态初始化完成后启动。
- 用 DWT 实现微秒延时，毫秒延时使用 HAL；不再改写或关闭 SysTick，使按键、任务及 IMU 超时使用连续毫秒时钟。
- IMU 增加有效帧新鲜度检查、坏帧重同步和 UART 错误后的接收恢复；USART2 优先级高于控制定时器。
- 任务的故障检查与电机输出使用一致的低压、使能和停止判断。

`tests/test_control.c` 直接包含并执行交付的控制、驱动、任务状态机及 IMU 解析 C 源码。测试使用模拟 GPIO、编码器和时钟，在 Cortex-M4 仿真环境运行，覆盖运动学、PI 独立性、PID 跨界、串口帧解析、5 秒停车及蜂鸣器时长、单/双/长按、上电按住按键、90° 理想自行车模型转弯、反向运动不误完成、转弯超时、断流/欠压/使能停车、毫秒计数回绕和 PWM 通道输出。测试使用理想模型，不评估真实轮胎打滑、舵机滞后或电机负载。
