# V6 局部航向接收与纯追踪补偿

改动前快照已提交并推送：9cd98e6。本次代码尚未烧录。

USART1 接收 V6 32 字节帧，兼容 V1～V5；CRC 覆盖前30字节。XY 为后轴坐标 X右正、Y前正，不再叠加摄像头偏移。航向左正右负，单位0.01度。参考XY单位0.01厘米。航向标志独立于目标标志，失效或300ms超时清零；航向从不进入1秒目标保持缓存。黄线和路线逻辑同时支持V6。

保持已有丢线策略（包括用户设定的最长1秒XY保持以及黄线后恢复）；保持期间不叠加航向修正。本次未改变反向9字节寻线切换协议。

## 航向修正

默认 THG=0，纯追踪行为保持。THMAX=3度。

启用条件：最新目标和控制目标均小于150ms、最新目标有效、V6航向有效、非备用目标、末端曲率有效且不超过TGEX、控制器处于直道状态。参考点后轴Y必须25～55cm、X在±20cm内，航向在±30度内。

满足条件时：转角=纯追踪转角+限幅(THG×局部航向)。补偿变化率30度/秒，最终转角仍受底盘原有限幅。失效立即撤销补偿。此处利用末端曲率保守筛选直道，不能保证整个近端都是直道；出弯仍应先核对参考点所在路段，不建议大增益。

## VOFA

JustFloat，115200，8N1；共101通道 I00～I100，原I00～I92不变。

|通道|名称|
|---|---|
|I93|局部航向有效|
|I94|局部航向角(度，左正)|
|I95|航向参考X(cm，右正)|
|I96|航向参考Y(cm，前正)|
|I97|实际航向补偿角(度，左正)|
|I98|航向增益THG|
|I99|航向补偿限幅THMAX(度)|
|I100|航向补偿启用状态|

滑条发送内容：`THG=%.2f;`，范围0～1，步长0.01；`THMAX=%.1f;`，范围0～10，步长0.1。先THG=0核对I93～I96；低速确认方向后可从0.05逐步增加。THG=0立即关闭补偿，恢复默认也会关闭。I100=0时表示当前不满足补偿条件或增益为零。
