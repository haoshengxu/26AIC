# 后轴预瞄点 V3 接收接口

接收沿用 USART1（PA9/PA10，115200、8N1）的 Vision_ProcessByte 字节流入口。
固定14字节 AA 55 03 0E，CRC16/CCITT-FALSE覆盖前12字节，CRC小端。
V1/V2/V3按版本独立分派，旧协议保持兼容。

## 读取数据

```c
VisionTarget target;
Vision_GetTarget(&target); /* 原始接收快照，300ms通信诊断超时；控制请用Vision_GetControlTarget */
if (target.valid) {
    float x_forward_m = target.y_centi_cm * 0.0001f;
    float y_left_m = -((float)target.x_centi_cm) * 0.0001f;
    /* 交给后续路径控制器；本次只新增接收接口。 */
}
```

线上X向右为正，Y向前为正，每整数单位0.01cm。发送端已完成后轴坐标变换；不重复加安装偏移，不应用V2的-20cm居中补偿。

## 有效性

- flags只能为0/1，reserved必须为0；有效帧必须Y>0，无效帧必须X=Y=0。
- 合法无效帧保持link_alive，但立即valid=0并清空坐标，不沿用旧目标。
- 距离最近合法V3帧达到300ms，Vision_GetTarget将link_alive和valid清零；错误帧不会刷新时间。
- UART错误立即清除目标。读取者必须检查valid，不得仅按X=0判断居中。
- seq只用于诊断：重复计入duplicate_frames，非连续计入sequence_discontinuities；允许重启和65535到0回绕。
- 同一视觉样本可由发送端重复发送且序号递增，received_ms是通信接收时刻，不是曝光时刻。

## M3纯追踪控制

M3已使用V3目标。轴距145mm，X向右、Y向前，先将坐标换算为米：

`steer_left_rad = atan(-2 * 0.145 * X / (X*X + Y*Y))`

转角限幅±0.35rad（约20.05°），通过已有舵机映射转PWM；机械中心1576us（原A=-2°校准为新A=0；M4范围-25°～+29°，物理端点保持）。Ack_Kinematics分配两后轮速度，最高每轮0.8m/s，保留原速度PI。
当前1100us/rad的舵机映射需用实际前轮转角验证；前轮等效转角不能直接等同舵机转角。
使用XY计算实际前视直线距离，不固定使用408mm，不套用网页沿路径弧长；距离小于50mm拒绝控制并报状态10。

### 启停与故障

- VOFA发送 `M=3;TV=0.25;RUN=1;` 或按键启动，等待启动后新收到的有效V3帧；最多等待1秒。
- 默认0.35m/s，TV范围0.01～0.8m/s；`RUN=0;`停止。
- 原始接收接口收到无效帧仍立即标记无效；控制接口Vision_GetControlTarget独立保留最后有效XY，最多使用1000ms。无效帧、CRC错误和格式错误均不能刷新控制时间。
- 以最后一帧有效V3的接收时刻计时，达到1000ms时停车回正（控制周期10ms）。期限内收到有效V3就更新XY并重新计时；X=0同样有效，序号仅诊断。UART错误、V1 STOP及电源/使能异常仍立即停车。停车后数据恢复不会自动起步，需重新RUN=1。
- 启动必须等待启动后收到的新有效V3，不能使用启动前缓存；无效帧不计为启动用的新目标。V1/V2仍可解析，但不能驱动或续期M3。
- TKP/TKD/TKS/TDF已拒绝，原PD/Stanley不再参与M3；TRESET=1恢复默认速度。前视选择在Jetson端配置。

### 1秒保持的诊断说明

I14/I22和I16显示最近接收结果；无效帧会清零这些原始坐标，I16=0。I21显示控制缓存是否可用；因此I16=0或通信诊断300ms超时而I21=1时，仍可处于最多1秒的盲走阶段。OLED M3显示正在使用的缓存XY。控制缓存的received_ms是最后有效V3接收时间，原始接口received_ms是最近合法报文时间，两者不同。

## 按目标X减速（M3）

先取目标横向坐标的绝对值（左右对称），超过阈值才减速：

`车体目标速度 = clamp(TV - TXK * max(abs(X_cm) - TXTH, 0), min(TVMIN,TV), TV)`

这是减速后的后轴中心目标速度，阿克曼运动学随后分配内外轮速度；外轮可比该值快，但每轮仍不超过0.8m/s。实际轮速由速度PI跟随。
X是目标相对后轴的横向坐标，随路径形状和前视位置变化，不是车辆到中心线的实际横向误差。

| 命令 | 默认值 | 范围 | 单位/意义 |
| --- | --- | --- | --- |
| TV | 0.35 | 0.01～0.8 | m/s，直道基础速度 |
| TXTH | 5 | 0～327.68 | cm，横向坐标绝对值超过该值开始减速 |
| TXK | 0.020 | 0～1 | 每超出阈值1cm降低多少m/s；0关闭减速 |
| TVMIN | 0.27 | 0.01～0.8 | m/s，最低转弯目标速度；大于TV时以TV为上限 |

默认TV=0.35、TXTH=5、TXK=0.020、TVMIN=0.27时，abs(X)为0/5/6/7/8/9cm，车体目标速度分别为0.35/0.35/0.33/0.31/0.29/0.27m/s；超过9cm保持0.27m/s。

### VOFA配置

保留JustFloat、34通道、115200 8N1。新增三个滑条或数值输入框，发送ASCII命令并以分号结束（参数位置按VOFA控件替换）：

- 阈值：发送 `TXTH=5;`，单位cm；建议调试控件范围0～30，步长0.5。
- 减速力度：发送 `TXK=0.01;`，建议调试控件范围0～0.05，步长0.001；数值越大减速越明显。
- 最低速度：发送 `TVMIN=0.10;`，建议调试控件范围0.05～0.25，步长0.01。
- 基础速度：发送 `TV=0.25;`。

启动示例：`M=3;TV=0.35;TXTH=5;TXK=0.020;TVMIN=0.27;RUN=1;`
观看I14目标X、I28基础速度、I29阈值、I30力度、I31最低速度、I32减速后速度和I0/I1实测轮速。丢线时原始X可能清零，但控制仍在1秒内使用缓存XY，因此减速也按缓存X计算。
运行中参数可实时调整，下一控制周期生效。目标X变小时速度按公式恢复；目前不额外加入加减速斜坡。
参数仅保存在RAM，重启或TRESET=1恢复代码默认值；M1/M2/M4不使用此减速。
