# Demo1 四模式：视觉循迹与 VOFA 调试

## 模式与速度

| 模式 | 功能 | 默认速度 | 启动方式 |
|---|---|---|---|
| M1 | 保持启动航向行驶 5 秒 | 后轴中心 0.3 m/s | USER 单击 |
| M2 | 前进完成 90°转向 | 后轴中心 0.3 m/s | USER 单击 |
| M3 | C30D 的 PD＋Stanley 视觉循迹 | 后轴中心 0.25 m/s | USER 单击授权，再等新的有效 V2 距离帧 |
| M4 | 原 Demo1 手动调速/转角，同时显示视觉距离 | 左右轮各 0.3 m/s，转角 0° | USER 单击或 VOFA RUN=1; |

双击按 M1→M2→M3→M4→M1 切换，切换先停车；长按停车。上电停在 M1。

ACK_MAX_WHEEL_SPEED_MPS=0.8f 对所有模式生效，是左右轮目标速度的绝对值上限。M1/M2/M3 超限时同比缩放左右轮，保留转弯比例；M4 命令范围为 -0.8～0.8 m/s，越界拒绝，输出层再限幅。这不是实际测得轮速的硬件限速器，瞬态超调仍取决于轮速 PI 与机械响应。

## 串口与硬件

- USART1：PA9 TX、PA10 RX，115200 8N1，接 Jetson。Jetson TX 接 PA10，Jetson RX 接 PA9，共地，3.3 V TTL。本版 USART1 接收视觉报文，不主动回复。
- USART2：PA2/PA3，保留 IMU。
- USART3：PC10 TX、PC11 RX，保留 VOFA（未采用 C30D 的 PD8/PD9），115200 8N1。
- CubeMX 保持本机 6.12.0；系统时钟 168 MHz、PLLQ=7，RTC HSE 分频为 8，原时钟修复保留。

## USART1 V2 距离报文

采用 C30D 原协议，14 字节；多字节字段小端。

| 字节 | 内容 |
|---|---|
| 0～1 | AA 55 |
| 2 | 02：V2 |
| 3 | 0E：长度 14 |
| 4～5 | uint16 序号，每帧递增，允许回绕 |
| 6 | 1=距离有效，0=失线/无效 |
| 7～9 | 00 00 00，保留 |
| 10～11 | int16 横向距离，单位 0.01 cm=0.1 mm；无效时必须为 0 |
| 12～13 | CRC16/CCITT-FALSE，覆盖 0～11 字节；poly=0x1021，init=0xFFFF，无反射，xorout=0，CRC 小端 |

视觉端发送的是相机中心到同一边沿的有符号距离，居中时为 -20.00 cm（线上 int16 = -2000）。单片机按 `误差原始值 = 接收原始值 - (-2000)` 换算为居中误差，再供循迹、OLED 和 VOFA 使用；收到 -20 cm 时误差为 0，-18 cm 时为 +2 cm，-22 cm 时为 -2 cm（恢复最初极性，不再取反）。换算在 32 位整数中进行并限幅到 int16；无效帧仍要求线上距离为 0，内部误差也置 0。居中基准在 `HARDWARE/distance_measurement.h` 的 `DISTANCE_CENTER_RAW` 中调整（每单位 0.01 cm）。建议每 20～50 ms 发送新帧。接收层具有帧头重同步、长度/版本/保留位/CRC 检查，拒收错误数据。

M3 使用 V2 距离，不使用 V1 的速度/转角指令。V1 解析保持兼容，合法 V1 停车/失线事件仍可停止 M3；V1 运动报文不能启动或续期 M3。

## M3 控制和保护

移植 BALANCE/tracking_control.c/.h、tracking_config.h；控制为 Kp*e + Kd*de/dt + atan(k*e/max(abs(v),0.1)) + 可选航向项。默认 Kp=5.45、Kd=0.30、k=0.6，微分滤波时间常数 0.08 s，前轮转角限幅 ±0.35 rad。

当前 V2 没有目标航向字段，生产代码未调用航向设置接口，因此航向项为 0。M3 无需 IMU 有效；M1/M2 仍要求有效 IMU。

- 先选 M3 再单击 USER，进入 WAIT；授权前收到的旧帧不会直接启动。
- 等待新有效 V2 帧最多约 1 秒，超时停车。
- 运行中临时断流或收到 V2 无效/失线帧，继续使用最后一次有效距离计算控制；距最后有效帧达到 1000 ms 时停车。期间接收一直开启，新有效帧及时更新控制并重新计时，重复、乱序、CRC 错误及无效帧不续期。
- USART1 硬件错误或合法 V1 停车事件仍立即锁存停车；V2 失线按上述 1000 ms 宽限处理。超时停车后需重新授权，新帧不会自动启动车辆。
- 故障恢复后仍需重新按 USER 授权。
- 欠压、使能关闭、Check 非零时，各运行模式均停车。

视觉距离仍沿用 C30D 的图像中心线交点距离语义，不是已完成前轴坐标标定的标准 Stanley 横向误差；需结合相机安装、标定和实车调参验证。

## M4 距离显示与手动调试

选中 M4 即可看距离，无需启动电机。OLED 每 3 秒切换一次距离页与原底盘状态页；距离页显示运行状态、有效性、厘米距离、方向、序号、数据年龄及 CRC 错误数。超过 250 ms 无有效接收时显示 TIMEOUT，距离显示 ---。

M4 启动后直接使用手动速度与转角，不进行视觉纠偏。距离无效或 USART1 断流不会停止手动调试；USART3 断开也不会自动停车。USER、RUN=0; 和使能可停车。停车后轮速目标归零、舵机回中，手动设定保留；重新上电恢复 0.3/0.3/0。

## VOFA 变化

仍选择 JustFloat，约 20 Hz；现在每帧 34 个 float32，加 00 00 80 7F，总长 140 字节。I0～I13 顺序不变，I9/I10/I11 改称 M4 的左轮/右轮/转角设定。

手动调试命令改为：`M=4;V=0.3;A=0;RUN=1;`。L/R/V 滑条范围改为 -0.8～0.8，建议步进 0.01。A 调试范围为 -27～27°。RUN=1 可授权启动 M3 或启动 M4；M=3; 只选择循迹模式，需按 USER 或发送单次 RUN=1; 授权。RUN=0; 可停止任何模式。

| 新通道 | 名称/单位 |
|---|---|
| I14 | 视觉横向距离 cm，无效时 0，必须同时看 I16 |
| I15 | 距离状态：0 WAIT、1 VALID、2 INVALID、3 TIMEOUT、4 UART错误 |
| I16 | 距离有效：1/0 |
| I17 | 最近接收的距离序号 |
| I18 | 距离帧年龄 ms，无帧为 -1 |
| I19 | 当前 M3 控制横向误差 m，未运行时 0 |
| I20 | 当前 M3 前轮转角指令 °，未运行时 0 |
| I21 | M3 输入是否可用：1/0（1000 ms 时效与序号校验）；不代表已启动 |

I7 状态保留原 0～6，新增 7 WAIT、8 LINK错误、9 远程停止、10 控制异常。I14～I18 用的是距离显示状态（250 ms）；I21 用的是运动状态（1000 ms），两者时效不同。
