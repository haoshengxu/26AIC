# M4 轮速 PI 在线调试

先烧录当前编译版本；USART3 115200 / 8N1 / JustFloat，86 通道（I00～I85）。

准备命令（保持停止）：`M=4;V=0;A=0;`
启动并设置双轮目标：`RUN=1;V=0.20;`
只改左/右轮目标：`L=0.20;`、`R=0.20;`。范围 ±1.6 m/s。
观察闭环制动：运行中 `V=0;`；结束调试 `RUN=0;`。
M4 不执行黄线自动停车，测试时需自行停止。

| 参数 | 默认 | 滑条发送内容 |
|---|---|---|
| 左轮 Kp | 73897 | `LKP=%.0f;` |
| 左轮 Ki | 4535 | `LKI=%.0f;` |
| 右轮 Kp | 73897 | `RKP=%.0f;` |
| 右轮 Ki | 4535 | `RKI=%.0f;` |

仅 M4 接受这四项命令，Kp 范围 0～100000、Ki 范围 0～10000，支持小数。修改保存在 RAM；切换模式后继续使用，重启恢复代码默认。TRESET 不重置轮速 PI。修改某轮 Kp/Ki 后会清除该轮的积分及控制状态，另一轮不重置（与 DIANSAI 调参行为一致）。命令不改变轮速目标，也不自动启动电机。

通道 I00/I03 = 左轮实际/目标速度；I01/I04 = 右轮实际/目标速度，单位 m/s。
新增 I76 左 Kp、I77 左 Ki、I78 右 Kp、I79 右 Ki。此前通道编号不变。

控制周期 10 ms，现为参考 DIANSAI 的位置式 PI（其速度环默认 Kd=0）：

- e = 目标速度 − 实际速度（m/s）。
- integral += e，P = Kp × e，I = Ki × integral。
- PWM = clamp(P + I, -16700, 16700)，下发时取整。
- 计算本次输出后，将下一周期保留的 integral 限制到 ±1.5，与参考的 ±150（cm/s 误差累计）按单位换算对应。
- Ki 是每周期系数，没有显式乘 dt。参考周期 5 ms，当前是 10 ms，因此参数不可直接跨工程照搬。
先以低速阶跃比较实际/目标速度，一次只调整一侧一个参数。需要重新整定时先把 Ki 调小或置零观察比例响应，再逐步增加 Ki 消除稳态误差；若振荡、超调或停后反转明显，应减小相应增益。架空测试不能代替落地验证。
本次没有修改默认 Kp/Ki，也未烧录或发送启动命令。

## PI 输出诊断通道

原 I00～I79 编号不变，新增：

| 通道 | 建议名称 | 含义 |
|---|---|---|
| I80 | 左轮PWM输出 | PI 限幅并取整后下发的带符号 PWM 指令 |
| I81 | 左轮P输出 | Kp × 当前误差 |
| I82 | 左轮I输出 | Ki × 累计误差 |
| I83 | 右轮PWM输出 | PI 限幅并取整后下发的带符号 PWM 指令 |
| I84 | 右轮P输出 | Kp × 当前误差 |
| I85 | 右轮I输出 | Ki × 累计误差 |

单位均为 PWM 计数，输出范围 ±16700，PWM 周期满量程约 16800。
当前轮子正向约定下，PWM 正为正转驱动，负为反转驱动指令；它不是测得的电流或力矩。
总输出为本次 P + I，再限幅取整；未饱和时 I81+I82 约等于 I80（取整差异小于 1），右轮同理。
P/I 输出为总输出饱和前的贡献，饱和时两者之和可超过实际 PWM。参考工程在输出计算后限制积分，因此本次 I 可包含一次越界误差，保存给下周期的积分已限幅。

通道取同一临界区中的最新控制快照；PI 100 Hz，VOFA 20 Hz，因此单个 10 ms 的 P 输出变化可能未被采到，波形不能当作全部控制周期记录。
RUN=0 或控制保护关闭时，左右 PWM 与 P/I 输出全部清零。保持 RUN=1 而 V=0 时仍运行零速闭环，可观察转动轮子后编码器反馈与反向 PWM 是否出现。

每帧现为 348 字节（86 个 float + JustFloat 尾帧）。无需更改串口 115200/8N1 设置。默认 Kp/Ki 为 73897/4535，M1～M4 共用新的位置式轮速环；采样周期及速度单位不变。

## 移植范围

参考：F:/Desktop/26电赛/TI板子小车控制代码/DIANSAI/empty_mspm0g3507_nortos_ticlang/user/pid/pid.c 的 pid_formula_positional，以及 APP/app_pid.c 中速度环 Kd=0、积分限幅和调参后重置逻辑。

保留 Demo1 电机的 PWM 计数单位与驱动方向，未套用 TI 小车的百分比输出增益、静摩擦前馈、速度前馈、目标加速度/jerk 整形和 PWM slew。这些外层功能涉及不同底盘标定；M4 仍直接下发速度目标。

在固定增益且未发生限幅/重置时，位置式 PI 与原增量式 PI 可等价；这次切换主要使 P/I 含义直观，并采用参考的积分限幅，不能单凭改公式保证加速/制动更快。

I81/I82/I84/I85 现应命名为 P输出/I输出；旧 VOFA 配置中的“增量”只是旧标签，不再适用于新固件。通道数量仍为 86，编号不变。

## GMR 测速配置修正

电机已确认减速比 1:30，编码器按电机轴 500 ppr。TIM2/TIM3 改为 TIM_ENCODERMODE_TI12（四倍频），CubeMX 同步 EncoderMode；软件 EncoderMultiples=4，与硬件一致。此前 TI1 是两倍频而软件除以四倍频一圈计数，因此旧回传速度约为实际速度一半。

现在每个输出轴/车轮整圈预期 4×500×30=60000 计数，10 ms 采样；轮径仍按 65 mm，周长约 0.2042 m。实际转一圈或滚动一米的测速积分可用于校准：推行一米时，对实际速度按时间积分应接近一米。正向推动时两轮回传均应为正。

先停止运行再烧录；新固件的物理轮速尺度发生变化，应以低目标速度重新整定，旧显示速度不能直接和新曲线比较。该修正尚未在实际电机上测量验证，500 ppr 的厂家口径和轮胎实际滚动周长仍需实测核对。

## Kp 调参上限

LKP/RKP 当前接受 0～100000（此前 10000），LKI/RKI 仍为 0～10000。
接收端数字解析上限同步为 100000，各命令仍执行各自范围校验。
VOFA 的 Kp 滑条上限也需设为 100000；发送格式仍为 LKP=%.0f; / RKP=%.0f;。
以 I76/I78 回传为实际生效值，不以滑条数值代替确认。超过上限的命令计入 I13 拒绝数。
例如 LKP=12673; 已可被接受；此修改不改变默认增益、积分限幅或 PWM 输出上限。
