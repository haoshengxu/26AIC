# M3：VOFA 在线循迹调试

## 连接

Jetson 的 TX 接 PA10（USART1 RX），GND 共地，持续发送 V2 距离帧（协议见 README_四模式视觉与调试.md）。VOFA 连接 USB 转 3.3 V TTL 串口：PC10 接适配器 RX、PC11 接适配器 TX、GND 共地。两路串口都为 115200、8N1、无流控。

VOFA 选择对应 COM 口，接收引擎选择 JustFloat。约 20 Hz 上传，34 个小端 float32 加 00 00 80 7F，共 140 字节。数据包不混入 ASCII 日志。接收区需要查看原始数据时选 Hex；乱码文本不是通信失败。

## 命令与控件

左侧新增命令，模式选 Str/ASCII；使用英文半角分号结尾。参数滑条绑定命令，Float 参数替换 %f。固定按钮只配置一个发送事件。不要连续发送 M=3;，因为每次选模式都会停车。

| 名称 | 命令 | 默认值 | 范围/建议步进 |
|---|---|---|---|
| 选择 M3 | `M=3;` | — | 单次按钮，切换后停车 |
| 启动/授权 | `RUN=1;` | — | 单次按钮，M3 进入 WAIT，M4 直接按手动目标运行 |
| 停车 | `RUN=0;` | — | 单次按钮，所有模式有效 |
| 循迹速度 | `TV=%f;` | 0.25 m/s | 0.01～0.8，步进 0.01 |
| 横向 P 系数 | `TKP=%f;` | 5.45 rad/m | 0～10，步进 0.05 |
| 横向 D 系数 | `TKD=%f;` | 0.30 rad·s/m | 0～2，步进 0.005 |
| Stanley 系数 | `TKS=%f;` | 0.6 /s | 0～10，步进 0.05 |
| 微分滤波时间常数 | `TDF=%f;` | 0.08 s | 0～1，步进 0.01 |
| 恢复 M3 参数 | `TRESET=1;` | 上述默认值 | 不切换模式、不自动启动 |

TV 是后轴中心期望速度。所有轮子的目标仍限制在 ±0.8 m/s，转弯外轮超限时整组目标同比缩小，因此车中心实际目标可能小于 TV。
M4 的 L/R/V/A 命令仍保留，但不能调整 M3。M3 转角由循迹算法计算，用 TKP/TKD/TKS 调节，不使用 A 强制舵机角度。

参数可停车预设，也可运行中修改；下一控制周期使用新参数。参数只保存在 RAM，切换模式或停车保留，上电恢复默认。TDF 修改和 TRESET 会清除微分历史，避免旧滤波状态造成跳变。参数上下限只是软件接受范围，不代表经过实车验证的最佳值。

## 使用顺序

1. 开启两路串口，Jetson 持续发有效 V2 距离。查看 I14/I16/I21，确认距离方向和有效性。
2. 发送 `M=3;TRESET=1;TV=0.25;`，设置低速默认参数。
3. 发送 `RUN=1;`。状态先进入 7 WAIT，新有效帧到达后进入 1 RUN。没有新帧约 1 秒后 LINK 错误，不会凭旧帧启动。
4. 调参数时逐项修改并看回读、误差和输出；例如 `TKP=1.2;`。要单独观察 PD，可设 `TKS=0;`；只观察 Stanley 项可设 `TKP=0;TKD=0;`。
5. 发送 `RUN=0;` 停车。不要把 TV=0 当停车指令，TV 最小接受 0.01 m/s。

启动仍要求电压不低于 10 V、使能打开、无 Check 故障。M3 达到 1000 ms 无新可用视觉帧、USART1 异常仍停车；有效数据恢复不会自动重启，需要再按 USER 或单次 RUN=1;。不要设置循环自动重发启动命令。VOFA 断开本身不会停车，Jetson 仍持续有效输入时 M3 会继续运行。

参数调节、协议与状态机已通过实际 C 源码仿真；尚未进行实车、相机或 VOFA GUI 联调。增益需结合实际相机距离标定、舵机方向和轮速反馈调整。

官方配置参考：[JustFloat](https://www.vofa.plus/docs/learning/dataengines/justfloat/)、[命令与参数绑定](https://www.vofa.plus/docs/learning/start/data_cmd_parameter/)、[滑条](https://www.vofa.plus/docs/learning/widgets/slider/)。

M3 丢帧宽限：沿用最后有效偏差最多 1 秒，期间持续接收；收到新有效帧就更新。V2 失线/无效帧不清除历史控制输入，也不刷新其时效。显示层仍按 250 ms 时效显示无效，故 I16=0 时 I21 可能暂时仍为 1；车辆运行状态以 I7 判断。启动前无历史有效帧时仍保持静止等待。
# M3 第1、3条黄线入弯新增参数

当前JustFloat为131通道（I00～I130），528字节/帧，20Hz。第1条分别发送 `T1BD=%.1f;`、`T1BA=%.1f;`、`T1BV=%.2f;`、`T1BMIN=%.2f;`、`T1BMAX=%.2f;`，第3条对应 `T3BD/T3BA/T3BV/T3BMIN/T3BMAX`。分别控制编码器实测直行距离(cm，0～200)、向右转角（输入正数）、车体速度、最低总盲走时间、包含直行的总恢复上限；默认第1条为0cm、8.9°、0.58m/s、0.57s、1.00s，第3条为7cm、15.2°、0.51m/s、1.00s、2.80s。

原I00～I114编号保留。I115/I116回读T1BD/T3BD，I117显示本次直行段有符号净行程(cm，达到距离后冻结)，I118显示直行剩余距离(cm)，I119/I120/I121显示上电以来左右轮/后轴中心有符号累计行程(cm)。I111显示阶段，I90显示总窗口剩余秒数。旧 `T1BT/T3BT` 仍接受并在I103/I107回读，但**不再影响直行**；I112停用固定0。将旧直行时间滑条改发BD并绑定I115/I116。

参数每次起步锁存；左右轮原始编码器位移平均作为后轴中心行程，倒退扣减、零轮速不前进，达到直行距离才允许右转或视觉接管；最低总时间及连续3帧条件同时保留。总上限到时，即使距离不足也先停车；距离未完成时新视觉帧不能绕过，需排查后重新启动。窗口内视觉暂时无效会回到本次入弯动作，不重新计时或重做直行。M3第2条及M5不使用这些新增参数。范围、完整状态和独立2.5秒寻线切换说明见 [黄线停车调试](README_黄线停车调试.md) 顶部当前版本章节。本文旧通道总数如与此处冲突，以此处为准。

M3/M5第4条黄线车头保留距离已独立：M3使用 `TFDIST3=%.1f;`（I91），M5使用 `TFDIST5=%.1f;`（新增I122），默认分别9cm和2cm、范围均0～100cm。旧 `TFDIST` 只修改M3；前3条 `TTDIST` 保持共用。详见 [黄线停车调试](README_黄线停车调试.md) 顶部。

## 标定里程清零按钮与减速位置记录

新增固定按钮“标定里程清零”，单次发送 `ORESET=1;`，数字显示绑定 **I123，单位cm**。只接受数值1。I123从上次清零位置起记录后轴中心有符号净行程，向前增加、倒退扣减、停车保持，上电为0。转弯计入沿路线行程，不是两点间的几何直线距离；手推且RUN=0也能测量。

在统一的路线起点点击一次清零，然后沿路线记录“开始减速位置I123、恢复速度位置I123、计划速度”。停止、启动、切换模式、黄线停车/起步都不自动清零。此按钮在所有模式及运行中可用，只重设标定原点，不切换运行状态或直接改电机/舵机目标，不改当前黄线入弯的距离/计时；里程区间限速会在下一周期按新里程重新判断。I119/I120/I121上电累计里程继续保持。VOFA界面配置文件未改写。

## M3第1、3条黄线后的两段里程限速

| 控件 | 滑条发送内容 | 范围 / 步进 | 默认 | 回读 |
|---|---|---|---|---|
| 第1段起点 | `TE1S=%.1f;` | 0～10000 cm / 0.1 cm | 178 cm | I124 |
| 第1段终点 | `TE1E=%.1f;` | 0～10000 cm / 0.1 cm | 239 cm | I127 |
| 第3段起点 | `TE3S=%.1f;` | 0～10000 cm / 0.1 cm | 759 cm | I128 |
| 第3段终点 | `TE3E=%.1f;` | 0～10000 cm / 0.1 cm | 830 cm | I129 |
| 两段共用限速 | `TEV=%.2f;` | 0.05～1.60 m/s / 0.01 m/s | 0.30 m/s，待实车调整 | I125 |

M3确认第1条黄线后，仅在I123处于 **[178,239)cm** 时启用第1段限速；确认第3条后，仅在 **[759,830)cm** 时启用第3段限速。起点包含、终点不包含，两段均从同一个ORESET标定起点累计，不从黄线处重新计距离。I126显示是否生效（0/1），新增I130显示当前段（0无、1第1段、3第3段）。原 `TEDIST` 保留为 `TE1S` 的兼容别名。

限速按TEV作为速度上限，按TDEC逐步减速；更低的原有弯道/丢线/黄线制动速度优先，停车保持0。普通巡线和对应黄线后的盲走都适用；M5不使用这两段。0.30m/s只是暂定初值。确认下一条黄线（第2或第4条）时立即结束对应区间资格，不再等停车或等待完成；黄线本身的制动、停车及终点流程继续正常执行。

达到区间终点后，该段在本次任务中结束，倒退回区间、重新清零或修改边界都不会重新启用。尚未到终点时，倒退到起点前或ORESET使距离不在区间内，会在下一控制周期退出限速；之后重新进入区间仍可启用。ORESET只改标定原点，不清黄线状态、入弯距离/计时或已结束标志。新任务清除区间状态，但不清I123；应在相同物理起点先ORESET，再启动任务。

四个边界可按任意顺序独立修改；某段起点不小于终点时，该段暂不生效，调整成起点小于终点后才重新检查。已结束的段仍保持结束，直至新任务。TEV实时生效；参数保存在RAM，重启或TRESET恢复默认。

默认配置：`ORESET=1;TE1S=178;TE1E=239;TE3S=759;TE3E=830;TEV=0.30;`，然后按原方式启动。解除区间限速后回到原速度规划，仍受起步加速、弯道和安全限制。当前共131通道，528字节/帧，20Hz。
