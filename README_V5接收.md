# V5 黄色胶带接收

V5 接收已接入黄线停车、等待和重新起步；控制与 VOFA 配置见
[黄线停车调试](README_黄线停车调试.md)。

## 报文与兼容

USART1，115200、8N1。V5 为 `AA 55 05 19` 开头的固定 25 字节报文；
路线字段偏移 4～19 与 V4 相同，胶带标志在 20，uint16 小端距离在
21～22，CRC16/CCITT-FALSE 在 23～24，校验前 23 字节。

保留 V1～V4 接收。V5 路线沿用现有 V4 的纯追踪、曲率减速、双转向增益和起步加速度逻辑。
只有有效预瞄目标刷新最多 1 秒的盲走计时；胶带有效不能代替路线目标有效。

## 读取黄线数据

```c
VisionTarget visual;
Vision_GetTarget(&visual);
if (visual.link_alive && visual.version == 5U && visual.tape_detected) {
    float distance_cm = visual.tape_distance_y_centi_cm * 0.01f;
    /* 后续停车业务使用 distance_cm；本次没有添加动作。 */
    (void)distance_cm;
}
```

- `tape_detected`：当前最新完整有效报文中的胶带测量标志，独立于 `valid`、mode 和路线 flags。
- `tape_distance_y_centi_cm`：uint16，单位 0.01 cm，范围 0～65535，即 0～655.35 cm。
- 这是胶带外接框边界到后轴横线的非负纵向距离，不是胶带中心距离，也不是直线距离。
- 已由视觉端换算到后轴，不再加 31.1 cm。协议没有前后符号，不能单凭此值判断是否已经越线。
- 标志为 1、距离为 0 是有效测量；标志为 0 必须配零距离。
- 新报文标志为 0 时立即清零；新 V3/V4 报文、UART 错误或 300 ms 通信超时也清零。
- 读取时通过已有临界区获取完整快照；应周期调用 `Vision_GetTarget`，它负责检查超时。
- 不要从 `Vision_GetControlTarget` 读取黄线：其用途是保留运动目标，本次特意不向该快照复制胶带信息。
- 串口序号不是相机帧号，不要用收到几个包来重复进行视觉确认。

V5 严格校验标志范围、路线有效位依赖、有效曲率有限且非负、无效测量数值为零。
CRC 或字段错误不会刷新时间，也不会覆盖之前的有效快照，旧快照仍受超时限制。
旧 V4 无效字段仍沿用忽略并清零的兼容行为。

## VOFA 与验证

原有 I00～I66 保持不变，新增 I67～I75 黄线相关通道，总计 76 通道。
I34 协议版本收到 V5 后显示 5；黄线有效标志和后轴距离分别为 I67、I68。

ARM 仿真测试覆盖协议给出的 5 条完整报文、所有分包位置、胶带单独有效、
零距离/最大距离、跨版本清除、CRC/语义错误与重同步、300 ms 超时和计时回绕。
路线测试确认 V5 沿用曲率减速和起步限加速度，胶带单独有效不能续期盲走。
尚未进行实际相机、串口和车辆联调。
