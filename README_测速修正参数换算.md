# 四倍频测速修正后的默认参数

为尽量保留旧二倍频采集、四倍频换算时的实际运动表现，将运动速度与加减速度设定按 2 倍换算。比例基于 500 PPR、减速比 30、轮径 65 mm；尚未实车校准，不能保证完全复现旧运动。

| 参数 | 原值 | 新值 |
|---|---:|---:|
| TV | 0.45 | 0.90 |
| TVMIN | 0.30 | 0.60 |
| TSINGLE / TUNKNOWN | 0.25 | 0.50 |
| TFALL / THOLD / TSAT | 0.20 | 0.40 |
| TSTART | 0.40 | 0.80 |
| TACC | 0.215 | 0.430 |
| TDEC | 0.80 | 1.60 |
| TCK | 0.08 | 0.16 |
| TXK（V3） | 0.020 | 0.040 |
| TTDEC | 0.40 | 0.80 |
| 全模式轮速上限 | 0.80 | 1.60 |
| M1/M2/M4 默认速度 | 0.30 | 0.60 |

速度单位 m/s，加减速度单位 m/s²。距离、曲率阈值、时间、转向增益不变；新近实调的轮速 PI 保持 Kp=73897、Ki=4535，积分限幅不变。停止判定的 0.02 m/s 是真实低速阈值，保持不变。黄线停车采用视觉物理距离，TTDEC 换算只能保持假定制动能力，不能保证旧停车位置相同。

烧录后重启应用默认值。VOFA 控件旧数值可能覆盖新默认，按本表同步控件；TV 与轮速控件上限需允许新范围。实际参数以设备回传为准。
