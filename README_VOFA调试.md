# Demo1：USART3 与 VOFA+ 调试

## 接线与串口

使用 3.3 V TTL USB 串口：PC10（板端 TX）接 USB 串口 RX；PC11（板端 RX）接 USB 串口 TX；两端 GND 共地。
VOFA+ 选择对应串口，115200、8 数据位、无校验、1 停止位、无流控；接收协议选择 JustFloat。
上电后所有模式（含停车）均约每 50 ms 上传一帧。每帧 34 个小端 float32，加 00 00 80 7F 帧尾，共 140 字节。
USART3 不混发文本日志。printf 仍属于原 USART2 路径，USART2 继续连接 IMU。

## M4 行为

- 上电选择 M1，停车。双击 USER 按 M1 → M2 → M3 → M4 → M1 切换，每次切换先停车。
- M4 默认左右轮各 0.3 m/s，前轮等效转角 0°，对应初始舵机脉宽 1500 μs。
- 单击启停，长按约 0.5 s 停车；也可通过 VOFA 的 M=4; 和 RUN=1; 操作。
- M4 直接设置两轮独立速度和舵机，不运行航向 PID、不进行阿克曼左右轮分速，不要求 IMU 有效。
- 低于 10 V、PD3 使能关闭或 Check 非零，仍停车；恢复后需重新启动。
- M4 持续运行，没有 M1/M2 的完成时间限制。拔掉串口不会自动停车，需用按键或使能停止。
- 调参只改变 M4 设定。停车时可以预设数值，实际轮速目标保持 0、舵机保持中位；启动 M4 后应用。
- 参数不写 Flash；模式切换和停车保留设定，重新上电恢复 0.3、0.3、0。
- 速度单位为 m/s，0.3 表示 0.3 m/s，不是 PWM、rpm 或 5 cm/s。架空调试时可先发送 V=0;，再启动并逐步提高速度。
- 舵机角度是前轮等效转角，不是舵机轴的 0～180°角度；正为左转。没有角度传感器，上传的是输出脉宽换算的指令角度，并非实测角度。

## VOFA 命令

在左侧添加命令，选择 Str/ASCII。使用英文半角字符。建议用分号结束，避免不同版本的换行转义差异；真正的 LF 或 CRLF 也支持。
数值接受普通十进制正负数和小数，不接受科学计数法、NaN、Inf。越界或格式错误整条拒绝。

| 名称 | 命令内容 | 控件/范围 |
|---|---|---|
| 选择 M4（先停车） | `M=4;` | 单次发送按钮 |
| 启动 M4 | `RUN=1;` | 单次发送按钮；重复发送不会重置运行计时 |
| 停车 | `RUN=0;` | 单次发送按钮；所有模式均有效 |
| 左轮速度 | `L=%f;` | 滑条/数值控件，-0.8～0.8 m/s，步进 0.01 |
| 右轮速度 | `R=%f;` | 滑条/数值控件，-0.8～0.8 m/s，步进 0.01 |
| 双轮同步速度 | `V=%f;` | 可选滑条，同时修改两轮，-0.8～0.8 m/s |
| 舵机转角 | `A=%f;` | 滑条，-20～20°，步进 1° |
| 舵机回中 | `A=0;` | 单次发送按钮；运行时生效 |
| 恢复调试默认值 | `V=0.3;A=0;` | 单次发送按钮，不自动启动 |
| 选择 M1/M2 | `M=1;` / `M=2;` | 可选按钮，切换后停车，按 USER 启动 |

滑条右键绑定相应命令，参数使用 Float/字符串格式，控件当前值替换 %f。固定命令按钮只配置一次发送事件，避免按下/松开重复触发模式切换。不要循环发送 M=4;，它每次都会停车。
示例一次发送：`M=4;V=0.3;A=0;RUN=1;`。运行中发送 `L=0.2;R=0.3;A=10;` 即修改目标。
RUN=1 允许 M3/M4；M1/M2 仍用 USER 启动。拒绝启动时可查看状态通道和拒绝计数。

## 数据通道与界面绑定

收到帧后会出现 I0～I21（有些版本显示通道序号），按下表重命名，不需要发送订阅命令。

| 索引 | 名称 | 单位/含义 |
|---|---|---|
| I0 | 左轮实际速度 | m/s，编码器反馈 |
| I1 | 右轮实际速度 | m/s，编码器反馈 |
| I2 | 舵机输出指令角度 | °，由实际下发脉宽反算，存在整数脉宽量化 |
| I3 | 左轮当前目标速度 | m/s，停车为 0 |
| I4 | 右轮当前目标速度 | m/s，停车为 0 |
| I5 | 舵机脉宽 | μs，停车为 1500 |
| I6 | 模式 | 1/2/3 |
| I7 | 状态 | 0 READY，1 RUN，2 DONE，3 STOP，4 IMU错误，5 电源/使能错误，6 超时 |
| I8 | 电池电压 | V |
| I9 | M4 左轮设定值 | m/s，停车仍保留 |
| I10 | M4 右轮设定值 | m/s |
| I11 | M4 转角设定值 | ° |
| I12 | 接受命令计数 | 每成功执行一条加 1，上电清零 |
| I13 | 拒绝/接收错误计数 | 非法命令、超长行、缓冲区溢出等增加 |

建议添加两个轮速波形图：左轮绑定 I0/I3，右轮绑定 I1/I4；角度波形绑定 I2/I11。滑条显示设定值可绑定 I9、I10、I11；增加电压、模式、状态数值显示。

## 实现和验证

- HARDWARE/vofa_debug.c：USART3 字节接收环形缓冲、主循环命令解析、JustFloat 异步中断发送；控制中断不等待串口发送。
- BALANCE/mode_control.c：M4 状态、设定值、启停和保护；修改状态时短暂屏蔽中断，避免与控制周期竞争。
- CubeMX IOC 已启用 USART3 中断（优先级 3），IMU 优先级 1、控制定时器优先级 2。
- Keil 入口 MDK-ARM/Demo1.uvprojx。最新固件 firmware/ACKERMANN_YAW.hex / .bin；BIN 地址 0x08000000。
- 控制、协议、OLED 仿真运行实际 C 源码，报告位于 tests；尚未连接实物 VOFA/串口/底盘验证。
